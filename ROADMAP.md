# Roadmap

This document captures the intended order of work.

## v1 Goals

- freeze Excel-first schema
- implement workbook reader/writer
- implement validation
- implement sequence resolution and flattening
- emit resolved browser JSON
- implement browser player for image/video/YouTube/text overlays
- implement static local server
- implement CDP preview control
- support agent-friendly workflow

## v1 Explicitly Deferred

- multi-track audio
- transitions as first-class objects
- line-level text override patching
- advanced timeline editing UI
- complex export automation
